# Tag_Imaage_with_WD_14
这是一个基于 **WD14 本地模型**的图片自动打标工具，支持批量处理、GPU 加速、中英文标签输出等功能。使用 ONNX Runtime 进行推理，可替代 LM Studio 等外部服务，实现完全离线的图片标签生成。

### ✨ 核心特性

- 🚀 **高性能批处理**：支持批量处理多张图片，GPU 加速可达 10 倍提速
- 🌐 **中英文标签**：支持英文标签和中文翻译标签切换
- 💾 **断点续传**：已处理的图片自动跳过，支持中断后继续处理
- 🔍 **智能分析**：提供丰富的标签筛选、统计和管理功能
- 🎯 **置信度控制**：可调节标签置信度阈值，精确控制标签质量
- 📊 **小世界模式**：创建临时数据库进行局部数据分析
- 🖼️ **可视化界面**：完整的 GUI 界面，支持缩略图预览和标签管理

## 📦 安装步骤

## 📝 使用说明

### 主界面功能

#### 1. 目录管理
- **添加目录**：选择包含图片的文件夹
- **删除目录**：移除选中的目录
- **清空列表**：清除所有已添加的目录

#### 2. 处理设置
- **置信度阈值**：控制标签的最小置信度（默认 0.35，范围 0-1）
  - 值越高，标签越精确但数量越少
  - 值越低，标签越多但可能包含噪声
- **批次大小**：每批处理的图片数量（默认 16，范围 1-256）
  - GPU 用户可使用较大值（32-64）
  - CPU 用户建议使用较小值（8-16）
- **中文标签**：勾选后显示中文翻译标签

#### 3. 开始处理
1. 添加包含图片的目录
2. 调整置信度和批次设置
3. 点击"开始处理"按钮
4. 实时查看处理进度和日志

#### 4. 停止处理
点击"停止"按钮可中断当前处理，已处理的图片会保留在数据库中。

## 🔍 标签分析功能

点击"分析结果"按钮打开标签分析面板。

### 标签列表（左侧）

#### 过滤功能
- **包含框**：输入关键词筛选标签（支持多个关键词，用空格/逗号分隔）
- **排除框**：输入关键词排除不需要的标签
- **双击清空**：双击文本框可快速清空内容

#### 排序方式
- **频次(大-小)**：按出现频率从高到低排序
- **频次(小-大)**：按出现频率从低到高排序
- **名称**：按标签名称字母顺序排序
- **名称倒序**：按标签名称逆序排序

#### 统一标签
将筛选出的多个标签统一为一个标签：
1. 在"包含"框中输入要统一的标签
2. 点击"统一"按钮
3. 确认后自动替换并更新统计

### 操作模式（右上角单选框）

- **新**：清空当前结果，显示新标签的图片
- **加**：将新标签的图片添加到当前结果（去重）
- **减**：从当前结果中移除新标签命中的图片
- **交**：只保留同时在新标签中的图片（交集）

### 缩略图区域（中间）

- **左键单击**：在右侧预览大图和标签
- **双击**：用 XnView 打开图片（需配置路径）
- **右键单击**：显示该图片所在目录的其他图片

### 图片预览（右侧）

- 显示选中图片的大图预览
- 显示该图片的所有标签
- **双击标签**：将标签添加到"包含"框
- **右键标签**：将标签添加到"排除"框
- **保存按钮**：手动编辑并保存标签

### 高级功能

#### 小世界模式
创建临时数据库，仅包含当前筛选的图片数据：
1. 先通过标签筛选出感兴趣的图片
2. 点击"小世界"按钮
3. 在隔离环境中进行精细分析

#### 复制图片到目录
将当前显示的所有缩略图复制到指定文件夹：
1. 筛选出需要的图片
2. 点击"复制图片到目录"
3. 选择目标文件夹
4. 确认复制

#### 重新统计
从数据库重建标签统计数据：
- 清除缓存
- 重新计算所有标签的出现次数
- 刷新标签列表

## 🗄️ 数据库结构

### image_tags 表
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键，自增 |
| image_path | TEXT | 图片完整路径（唯一） |
| tags | TEXT | 标签字符串，逗号分隔 |
| created_at | TIMESTAMP | 创建/更新时间 |

### tag_stats 表
| 字段 | 类型 | 说明 |
|------|------|------|
| tag | TEXT | 标签名称（主键） |
| count | INTEGER | 出现次数 |

## 🎯 性能优化建议

### GPU 加速
- 确保安装了正确版本的 onnxruntime
- 增大批次大小（32-64）以充分利用 GPU
- 首次运行时会显示使用的执行提供者

### CPU 模式
- 使用较小的批次大小（8-16）
- 关闭其他占用 CPU 的程序
- 考虑升级到 GPU 以获得更好性能

### 内存优化
- 缩略图会自动缓存，大量图片时注意内存使用
- 定期重启程序可清理缓存
- 分析面板支持分批加载标签（每次 300 个）

## 🔧 常见问题

### Q1: 提示"WD-14 模型未初始化"
**A**: 检查模型文件是否存在于指定目录，确认已安装 onnxruntime。

### Q2: 处理速度很慢
**A**: 
- 确认是否使用了 GPU 版本
- 检查任务管理器中 GPU/CPU 使用情况
- 尝试调整批次大小

### Q3: 标签都是英文，如何显示中文？
**A**: 勾选界面上的"中文标签"复选框，需确保 `tag_translations.json` 文件存在。

### Q4: 如何修改模型路径？
**A**: 编辑代码第 89 行：
```python
self.model_dir = r"你的模型路径"
```

### Q5: 数据库文件在哪里？
**A**: 默认位于 `D:\projects\immich-booru-tagger-main\wd14_image_tags.db`，可在代码第 74 行修改。

### Q6: 如何备份数据库？
**A**: 
- 直接复制 `.db` 文件
- 使用"统一标签"功能时会自动备份
- 建议定期手动备份
